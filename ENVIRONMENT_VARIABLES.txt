==============================================================================
WarframeBOT - ENVIRONMENT VARIABLES
==============================================================================

All configuration comes from environment variables. bot.py calls
load_dotenv() at startup, so a file named ".env" next to bot.py is loaded
automatically.

Setup:
  1. Copy .env.example to .env
  2. Fill in the values below
  3. Start the bot:  python bot.py

NEVER commit your real .env file (it is already in .gitignore).

Summary
-------
  Variable          Used by          Required?
  ----------------  ---------------  --------------------------------------
  DISCORD_TOKEN     bot.py           YES (bot exits without it)
  OWNER_ID          /wm account cmds No (lets the owner use WFM_* below)
  WFM_JWT           market/seller    No (owner's account, preferred)
  WFM_EMAIL         market/seller    No (alternative to WFM_JWT)
  WFM_PASSWORD      market/seller    No (alternative to WFM_JWT)
  WFBOT_SECRET_KEY  /wm link         No (auto-generated into data/secret.key)
  WFBOT_DATA_DIR    /wm link         No (default "data")
  WFM_PLATFORM      bot.py           No (default "pc")
  LOG_LEVEL         bot.py           No (default "INFO")
  LOG_FILE          bot.py           No (default "log.log"; empty = console only)
  WFBOT_API_KEY     FastAPI service  No (API is open if unset)
  WFBOT_CORS        FastAPI service  No (defaults to "*")


------------------------------------------------------------------------------
DISCORD BOT
------------------------------------------------------------------------------

DISCORD_TOKEN
    Bot token for your Discord application.
    Where to get: https://discord.com/developers/applications
                  -> your application -> "Bot" tab -> "Reset Token"
                  (shown only once, so copy it immediately)
    Security    : Treat it like a password. If it leaks, reset it.

OWNER_ID
    Discord user ID(s) whose account commands (list, update_order, sold,
    unlist, my_orders, status) may use the WFM_* account below without
    running /wm link. Everyone else, and the owner once linked, acts only on
    the account they linked themselves with /wm link.
    Format      : one ID, or several separated by commas.
    Example     : OWNER_ID="123456789012345678,987654321098765432"
    Where to get: Discord -> Settings -> Advanced -> Developer Mode, then
                  right-click your name -> "Copy User ID".

WFM_PLATFORM
    Default platform for market lookups when a command's `platform` option
    isn't given: pc, ps4, xbox, switch or mobile. Default: pc.

LOG_LEVEL / LOG_FILE
    Log verbosity (DEBUG, INFO, WARNING, ...) and log file path. Logs always
    go to the console too; the file rotates at 2 MB (3 old files kept).
    Set LOG_FILE to an empty value to log to the console only.


------------------------------------------------------------------------------
LINKED ACCOUNTS (/wm link)
------------------------------------------------------------------------------

Each Discord user links their own warframe.market account with /wm link (a
private form: paste the JWT cookie, or sign in with email + password, in
which case only the resulting token is kept). Tokens are stored encrypted in
<WFBOT_DATA_DIR>/accounts.json. Tokens and passwords are never logged.

WFBOT_SECRET_KEY
    Fernet key that encrypts the stored tokens. If unset, one is generated
    into <WFBOT_DATA_DIR>/secret.key on first use. If the key is lost or
    changed, stored links can't be read and users must /wm link again.
    Make one: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
    Security : whoever has the key and accounts.json can act on the linked
               accounts. Keep both private and backed up.

WFBOT_DATA_DIR
    Folder for accounts.json and secret.key. Default "data" (in .gitignore).


------------------------------------------------------------------------------
OWNER'S WARFRAME.MARKET ACCOUNT FROM .env (optional)
------------------------------------------------------------------------------

Used by the OWNER_ID users when they haven't linked an account. The account
is "configured" when WFM_JWT is set, OR both WFM_EMAIL and WFM_PASSWORD are.

WFM_JWT
    Session token for your warframe.market account. Preferred, because
    password sign-in can be blocked by Cloudflare.
    Where to get: sign in at https://warframe.market in your browser and copy
                  the value of the "JWT" cookie.
    Note        : a pasted token can't be refreshed automatically. When it
                  expires the bot says so; paste a fresh one and restart.

WFM_EMAIL / WFM_PASSWORD
    Password sign-in, used only when WFM_JWT is empty. Stored in plain text
    in .env, so prefer WFM_JWT.

Signing in no longer changes your online status. Use /wm status for that.


------------------------------------------------------------------------------
FASTAPI SERVICE (uvicorn)
------------------------------------------------------------------------------

The API does NOT call load_dotenv(). Export the variables, or start with:
    uvicorn api.main:app --env-file .env

WFBOT_API_KEY
    When set, every /v1/* endpoint requires the header "X-API-Key: <value>"
    (HTTP 401 otherwise). /health is always open. Unset = no authentication.

WFBOT_CORS
    Allowed CORS origins, comma-separated. Default "*". Only GET is allowed.


------------------------------------------------------------------------------
NOT ENVIRONMENT VARIABLES (constants in the source)
------------------------------------------------------------------------------

  market/client.py   order cache 60 s, >= 0.34 s between requests, one retry
                     on HTTP 429/5xx, catalogues (items, riven/lich/sister
                     weapons, riven stats) refreshed every 6 h, item details
                     and sets cached 1 h, statistics 10 min
  market/seller.py   >= 0.4 s between requests
  wiki/client.py     search cache 5 min, page cache 15 min, category lists
                     12 h, 4 concurrent requests, 15 s timeout
  ui/paginator.py    dropdowns and buttons stop working after 10 minutes
                     (link buttons keep working)


------------------------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------------------------

"DISCORD_TOKEN is not set"
    The variable is missing or .env is not in the folder you launched the
    bot from. Check the file is named exactly ".env" (not ".env.txt").

"No warframe.market account is linked to you."
    Run /wm link. (Owners can alternatively set OWNER_ID + WFM_JWT.)

"warframe.market rejected the token (401): it has expired."
    Run /wm link again with a fresh JWT cookie (or update WFM_JWT).

API returns 401 "Missing or invalid X-API-Key"
    WFBOT_API_KEY is set. Send the header  X-API-Key: <value>.
